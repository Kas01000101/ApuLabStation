# Agent Guidelines

## UI / Design System

Antes de modificar cualquier interfaz de ApuLab:

1. Leer `DESIGN.md`.
2. Reutilizar `src/ui/tokens.ts`.
3. No inventar nuevos colores si existe un token adecuado.
4. No inventar nuevas familias tipograficas.
5. No introducir tamanos arbitrarios si existe un token.
6. Reutilizar componentes UI existentes.
7. No crear botones completos como PNG.
8. No usar emojis como iconos de produccion.
9. No instalar librerias UI sin justificar previamente una limitacion real de Phaser.
10. Mantener compatibilidad con `1280x720`.
11. Respetar legibilidad para ninas de 8 a 12 anos.

`DESIGN.md` y `src/ui/tokens.ts` son la fuente oficial de verdad visual de ApuLab.
