# Open Source Policy

ApuLab Research is an open-source research-software project.

## Source code

Software source code in this repository is licensed under the **MIT License**. See `LICENSE`.

## Original documentation and content

Original documentation and original project content are available under **Creative Commons Attribution 4.0 International (CC BY 4.0)** unless a file states otherwise. See `CONTENT-LICENSE.md`.

## Third-party materials

Dependencies, fonts, images, models, audio, and other third-party materials remain under their original licenses and terms. Their presence in this repository does not relicense them under MIT or CC BY 4.0.

## Research data

Open-source licensing does not make participant data public. Participant mappings, credentials, protected codebooks, private datasets, research exports containing restricted information, and production secrets are outside the scope of this open-source policy and must not be committed to the repository.

## Contributions

Code contributions are accepted under MIT unless explicitly stated otherwise. Original documentation contributions are accepted under CC BY 4.0 unless explicitly stated otherwise.

Contributors must only submit material they have the right to license.
